# 🧠 一、核心总纲（必读）

## 1. Data Agent: A Holistic Architecture for Orchestrating Data+AI Ecosystems

* **会议** ：ICDE 2025 / Keynote
* **重要程度** ：★★★★★
* **PDF** ：[https://dbgroup.cs.tsinghua.edu.cn/ligl/papers/DataAgent.pdf](https://dbgroup.cs.tsinghua.edu.cn/ligl/papers/DataAgent.pdf)

### 核心内容

* 提出 **Data Agent 概念**
* 三大能力：
  * 语义理解
  * 推理
  * pipeline 编排
* 覆盖：
  * Data Science Agent
  * Data Analytics Agent
  * DBA Agent

### 一句话总结

> Data Agent = 能理解需求 + 推理 + 自动调度数据工具的智能体系统

# ⚙️ 二、Data Agent 系统论文（重点）

## 2. AOP: Automated and Interactive LLM Pipeline Orchestration

* **会议** ：CIDR 2025
* **重要程度** ：★★★★★

### 核心思想

* LLM 自动拆解复杂查询
* 生成多步骤 pipeline
* 支持交互优化

### 本质

> Data Agent 的“规划与推理引擎”

## 3. iDataLake: An LLM-Powered Analytics System on Data Lakes

* **重要程度** ：★★★★★

### 核心思想

* 自然语言 → 分析 pipeline
* 支持：
  * 结构化
  * 半结构化
  * 非结构化数据

### 本质

> Data Agent 在真实数据湖场景中的落地

---

## 4. Unify: A System for Unstructured Data Analytics

* **会议** ：VLDB 2025
* **重要程度** ：★★★★☆

### 核心思想

* 面向非结构化数据（文本、文档）
* LLM + pipeline 执行

### 本质

> Data Agent 扩展到非 SQL 场景
